# MetroPT-3 Dataset — Preliminary Study Notebooks

This folder is designated for the preliminary study notebooks on the **MetroPT-3 dataset** (notebooks `01` to `04`, `03b`, and `03c`).

> **Note:** The MetroPT-3 preliminary study notebooks were not present in the original repository and are currently missing from this project directory. The benchmark study and demonstration dashboard focus on the **Intel Berkeley Research Lab** dataset located in `intel_lab/`.

Raw data for MetroPT-3 can be retrieved from the UCI Machine Learning Repository:
- **Dataset link:** [UCI MetroPT-3 Dataset](https://archive.ics.uci.edu/dataset/791/metropt+3+dataset)
